# Legal & Compliance

## Reverse Engineering

This project involves reverse-engineering the Max Payne LVL file format. This was done for the purpose of achieving interoperability with Blender, which is a permitted activity under:

- **DMCA Section 1201(f)** - Interoperability exemption.
- **EU Directive 2009/24/EC** - Permits decompilation for interoperability.

No game assets, copyrighted code, or proprietary executables are included in this repository.

## What This Repository Does NOT Contain

- ❌ No Max Payne game executables (`.exe`)
- ❌ No game assets (textures, models, sounds, levels)
- ❌ No original `MaxED.exe` or `MAXED.CHM` files
- ❌ No extracted `*.lvl` or `*.ldb` files
- ❌ No game documentation (`.chm`, `.pdf`, `.doc`)

Everything in this repository was created independently.
