- **[CFR](https://github.com/leibnitz27/cfr)** — Used for decompiling Java classes from the original Blender plugin. CFR is released under the MIT License.

- **[ldb-to-lvl](https://github.com/andrews05/ldb-to-lvl)** — Used to understand the LVL file format and to study how ldb files are converted to lvl. This project is licensed under the MIT License.

- **[Blender 2.79 Python API](https://docs.blender.org/api/2.79/)** — The Blender Python API documentation was referenced for writing the exporter script.

- **[Max Payne Modding Community](https://www.maxpayne.info/)** — Various community resources, discussions, and documentation were referenced to understand the game's file structures.
