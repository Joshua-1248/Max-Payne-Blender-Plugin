# Max Payne Blender Plugin

A Blender 2.79 plugin for exporting levels from Max Payne's LVL file format.

This plugin allows you to open `.lvl` files (Max Payne's proprietary level format) inside Blender, edit or view the level geometry, and re-export it back to LVL format for use in the game.

> **⚠️ Important:** This plugin requires you to own a legitimate copy of Max Payne and have the official MaxED tool installed.

---

## Features

- **Import LVL files** – Load Max Payne level geometry into Blender.
- **Export LVL files** – Save Blender scenes back to the LVL format.
- **Preserves game data** – Maintains original level structure, collision data, and object placement.
- **Blender integration** – Works directly within Blender 2.79's UI.

---

## Requirements

- **Blender 2.79** – This plugin is built for Blender 2.79. It may not work with newer versions.
- **MaxED (Max Payne Level Editor)** – Required for opening LVL files in the game. You must own a legitimate copy of Max Payne to legally use MaxED.
- **Python 3.x** – Included with Blender 2.79.
